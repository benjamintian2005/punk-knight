# Punk Knight

A Godot 4 game combining a rhythm-game half with a battle-game half.

- **Left side** — hit falling notes on lanes **D F J K** in time with the beat.
- **Right side** — a character fends off enemies that spawn and close in. Every note you hit fires a pulse: a **Perfect** hit damages nearby enemies, a **Good** hit knocks them back (no damage). Survive as long as you can — game over triggers a restart prompt (Enter).

## Running

Open the project in Godot 4 and press Play (`scenes/Main.tscn` is the main scene).
